# 코코포리아 로그 변환기

코코포리아(ccfolia)에서 내보낸 로그 HTML을 **왼쪽 얼굴 + 오른쪽 이름·대사** 형식으로 바꿔 주는 웹페이지입니다.
빌드가 필요 없는 정적 사이트라서 GitHub Pages에 그대로 올리면 됩니다.

## 사용 순서

1. **로그 불러오기**: 로그 `.html` 파일을 올리거나 내용을 붙여넣습니다.
2. **화자 분류**: 위쪽 분류 카드(인물 / 굵은 지문 / 얇은 지문 / +새 분류)에서 분류의 모양을 정하고, 화자마다 드롭다운으로 분류를 고릅니다.
   카드를 누르면 설정 창이 열리고, 인물형(얼굴·이름·대사)과 지문형(대사만), 굵게·기울임·밑줄·취소선, 정렬, 글자 크기, 글자색, 괄호 색을 바꿀 수 있습니다.
   바꾼 모양은 '예시 대사입니다.' 미리보기에 바로 보입니다. 기본 분류도 고치거나 지울 수 있습니다.
   인물형 화자에는 표시 이름, 이름 색, 얼굴 이미지(파일 또는 URL)를 넣을 수 있고, `제외`를 고르면 출력하지 않습니다.
   화자 목록은 `전체 / 화자 / 지문 / 제외`로 나눠 볼 수 있습니다.
3. **꾸미기·내보내기**: 테마, 얼굴 크기, 글자 크기, 글꼴, 판정 표 등을 고른 뒤
   - 얼굴 크기와 글자 크기는 슬라이더 옆 칸에 숫자로도 넣을 수 있고, 글꼴은 고딕·명조·세리프·손글씨·고정폭 묶음에서 고르거나 **+ 글꼴 추가**에 웹폰트 주소를 넣어 목록에 추가합니다. 구글 폰트 같은 CSS 주소, `.woff2`·`.woff`·`.ttf` 파일 주소, 눈누의 `@font-face` 코드를 받습니다.
   - **대사 수정** 탭에서 대사마다 오탈자를 고치거나 삭제·되살리기를 할 수 있습니다. 글자를 드래그해 굵게·기울임·밑줄·취소선·글자색을 넣을 수도 있습니다. 검색과 "고친 것만/삭제한 것만" 필터도 있습니다.
   - **HTML 파일 다운로드**: 브라우저에서 바로 열리는 완성 파일
   - **에디터용 코드 복사**: DHTML 에디터의 HTML 모드에 붙여넣을 코드
   - **에디터용 코드 txt 다운로드**: 위 코드를 `.txt` 파일로 저장 (코드가 길어 복사가 불편할 때)

## 설정 파일

1단계의 **설정 파일** 칸이나 3단계의 **설정 파일 저장**으로 화자 분류, 분류 카드, 꾸미기, 내 글꼴을 `.json` 파일 하나로 저장합니다.
다음에 1단계에서 **설정 파일 불러오기**로 그 파일을 올리면 그대로 적용됩니다. 로그를 먼저 불러와도, 나중에 불러와도 됩니다.
파일로 올린 얼굴 이미지도 함께 들어가므로 다른 컴퓨터나 브라우저로 옮길 때도 쓸 수 있습니다.

출력물은 에디터에서 깨지지 않도록 `<style>` 태그 없이 **인라인 스타일 + table**로만 만들어집니다.
화자 설정과 꾸미기 설정은 브라우저에 저장되어, 같은 이름이 나오는 다음 로그에도 그대로 적용됩니다.

## 이미지

- 파일로 올린 이미지는 200px 정사각형으로 잘라서 코드 안에 직접 넣습니다(data URI).
- 에디터가 data URI 이미지를 막는다면 이미지 호스팅에 올린 뒤 **주소(URL)** 를 넣어 주십시오.

## 로컬에서 실행

`index.html`을 더블클릭해 브라우저로 열어도 동작합니다.
주소창이 `http://`인 환경에서 확인하고 싶다면 폴더에서 간단한 서버를 띄웁니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000` 을 엽니다. 끌 때는 터미널에서 `Ctrl+C`를 누릅니다.

## GitHub Pages 배포

```bash
git init
git add .
git commit -m "코코포리아 로그 변환기"
git branch -M main
git remote add origin https://github.com/<아이디>/<저장소이름>.git
git push -u origin main
```

GitHub 저장소 → **Settings → Pages** → Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 두고 저장합니다.
잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

## 파일 구성

- `index.html`: 화면 구조
- `style.css`: 변환기 화면 스타일
- `app.js`: 로그 해석, 화자 분류, 출력 HTML 생성
