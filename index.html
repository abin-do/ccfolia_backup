로그 HTML 불러오기

코코포리아에서 내보낸 로그 파일(.html)을 올리거나, 파일 내용을 그대로 붙여넣으십시오.

설정 파일

화자 분류, 분류 카드, 꾸미기, 내 글꼴을 파일 하나로 저장해 두었다가 다음에 불러와 그대로 쓸 수 있습니다.

화자 분류

분류 카드를 누르면 글자 크기, 글자 모양, 괄호 색 같은 모양을 바꿀 수 있습니다. 인물형은 왼쪽에 얼굴, 오른쪽에 이름과 대사가 나오고, 지문형은 대사만 나옵니다. 화자마다 드롭다운에서 분류를 고르고, 제외를 고르면 출력하지 않습니다.

종류는 글꼴을 불러오지 못했을 때 대신 보여 줄 모양입니다. 글꼴 파일 주소나 @font-face 코드를 넣었다면 이름은 마음대로 바꿔도 됩니다.

가나다라 ABC 123 · 예시 대사입니다.

보는 사람의 컴퓨터에 그 글꼴이 있어야 보입니다. 없으면 같은 종류의 기본 글꼴로 나옵니다.

이 웹폰트는 HTML 파일 다운로드에는 불러오는 코드가 함께 들어갑니다. 복사한 코드와 txt에는 들어가지 않으므로, 에디터 쪽에 같은 글꼴이 있어야 보입니다.

대사·지문·괄호 색은 기본색입니다. 분류마다 다른 색을 쓰려면 2단계 분류 설정에서 고르십시오.

복사한 코드는 에디터의 HTML 모드에 붙여넣으십시오. 이미지를 파일로 올렸다면 코드 안에 이미지가 직접 들어갑니다(data URI). 에디터가 이런 이미지를 막으면 2단계에서 이미지 주소(URL)를 쓰십시오.

글자를 드래그해 고른 뒤 누르십시오

대사를 바로 고치면 출력에 반영됩니다. 삭제한 대사는 출력에서 빠지고, 되살리기로 다시 넣을 수 있습니다. 2단계에서 제외한 화자의 대사는 여기 나오지 않습니다.
