로그 HTML 불러오기

코코포리아에서 내보낸 로그 파일(.html)을 올리거나, 파일 내용을 그대로 붙여넣으세요.

화자 분류

인물은 왼쪽에 얼굴, 오른쪽에 이름과 대사가 나와요. 굵은 지문/얇은 지문은 이름 없이 가운데 정렬로 나오고, 제외하면 출력하지 않아요.

꾸미기

복사한 코드는 에디터의 HTML 모드에 붙여넣으세요. 이미지를 파일로 올렸다면 코드 안에 이미지가 직접 들어가요(data URI). 에디터가 이런 이미지를 막으면 2단계에서 이미지 주소(URL)를 쓰세요.
